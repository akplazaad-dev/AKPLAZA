# AK PLAZA 카드 사은혜택 자동 입력 프로그램

이번 달 **제휴 판촉 캘린더 PDF**를 읽어, **엑셀 양식(`사전고지(본부)` 시트)의
노란색 칸(주차별 카드 사은혜택 칸)**을 자동으로 채워 **새 엑셀 파일**을 만들어 주는
프로그램입니다.

> 🟡 **처음 사용하시나요?** → 먼저 [`사용설명서.md`](사용설명서.md) 를 보세요.
> 컴퓨터 초보자도 따라 할 수 있게 단계별로 아주 자세히 적어 두었습니다.

---

## 빠른 사용법 (윈도우)

1. **최초 1회**: `최초설치.bat` 더블클릭 (파이썬 필요 — 설명서 1단계 참고)
2. **매달**: 이번 달 PDF를 이 폴더에 넣고 → `실행하기.bat` 더블클릭
3. 결과 확인:
   - `..._결과.xlsx` : 노란색 칸이 채워진 완성 엑셀
   - `..._검토용.txt` : 사람이 눈으로 확인하는 참고용 정리

---

## 자동으로 채워지는 항목 (월간 공통 혜택)

한 달 내내 유효한 아래 혜택들이 **모든 주차 칸**에 정확히 입력됩니다.

- 신한Plus 발급① (전관 합산, 상품권)
- 신한Plus 발급② (첫결제 모바일상품권/캐시백)
- 신한Plus 정기 (APP쿠폰)
- PAYCO(포인트) ① 전관 / ② 해외명품·골드바 / ③ 무신사·나이키
- 가전 (네이버페이/NH)
- 가구 (네이버페이/NH)

**특정 날짜 행사**(A*CLASS, 멤버스페스티벌, 공판, 개점행사 등)는 PDF 디자인상
글자가 겹쳐 나올 수 있어, 자동 입력 대신 `..._검토용.txt` 에 정리하여
사람이 확인 후 직접 추가하도록 했습니다. (이유는 사용설명서 5단계 참고)

## 폴더 구성

```
.
├─ update_calendar.py     # 메인 프로그램 (파이썬)
├─ 최초설치.bat            # 최초 1회 라이브러리 설치 (윈도우)
├─ 실행하기.bat            # 매달 실행 (윈도우 더블클릭)
├─ requirements.txt       # 필요한 파이썬 라이브러리 목록
├─ 사전고지_양식.xlsx      # 엑셀 양식 (노란색 칸 포함)
├─ 사용설명서.md           # 초보자용 상세 설명서
├─ README.md              # 이 파일
└─ 예제/                   # 연습용 예제 PDF
```

## 개발자용 참고

- 언어/라이브러리: Python 3, `pdfplumber`(PDF 읽기), `openpyxl`(엑셀 편집)
- 명령줄 실행:
  ```bash
  pip install -r requirements.txt
  python update_calendar.py [양식.xlsx] [이번달.pdf]
  ```
  인자를 생략하면 프로그램 폴더에서 엑셀 양식과 가장 최근 PDF를 자동으로 찾습니다.
- 설정값(시트 이름, 노란색 칸 위치 등)은 `update_calendar.py` 상단 `[설정]` 영역에 모여 있습니다.
- 추출 규칙은 `월간혜택_추출()` 함수에 항목별로 정리돼 있어, PDF 양식이 바뀌면
  해당 항목의 정규식만 조정하면 됩니다.
