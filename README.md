# AK PLAZA 카드 사은혜택 자동 입력 프로그램

이번 달 **제휴 판촉 캘린더 파일(PPT 권장, PDF 가능)**을 읽어,
**엑셀 양식(`사전고지(본부)` 시트)의 노란색 칸(주차별 카드 사은혜택 칸)**을
자동으로 채워 **새 엑셀 파일**을 만들어 주는 프로그램입니다.

> 🟡 **처음 사용하시나요?** → 먼저 [`사용설명서.md`](사용설명서.md) 를 보세요.
> 컴퓨터 초보자도 따라 할 수 있게 단계별로 아주 자세히 적어 두었습니다.

---

## 빠른 사용법 (윈도우)

1. **최초 1회**: `최초설치.bat` 더블클릭 (파이썬 필요 — 설명서 1단계 참고)
2. **매달 (추천, 창 GUI)**: `프로그램 실행.bat` 더블클릭 → 창이 뜨면
   PPT 파일을 **드래그앤드롭** → `▶ 엑셀 만들기` 클릭 → `📂 결과 폴더 열기`
   - 오프라인에서 동작하며, 드래그가 안 되면 `파일 찾아보기` 버튼 사용
   - (대안) 창 없이 자동 처리: 폴더에 PPT를 넣고 `실행하기.bat` 더블클릭
3. 결과 확인:
   - `..._결과.xlsx` : 노란색 칸이 채워진 완성 엑셀
   - `..._검토용.txt` : 사람이 눈으로 확인하는 참고용 정리

## 채워지는 내용

**① 월간 공통 혜택** — 한 달 내내 유효하며 **모든 주차 칸**에 입력됩니다.

- 신한Plus 발급① (전관 합산, 상품권)
- 신한Plus 발급② (첫결제 모바일상품권/캐시백)
- 신한Plus 정기 (APP쿠폰)
- PAYCO(포인트) ① 전관 / ② 해외명품·골드바 / ③ 무신사·나이키
- 가전 (네이버페이/NH)
- 가구 (네이버페이/NH)

**② 특정 날짜 행사** — A*CLASS, 멤버스페스티벌, 신한카드플러스페스타, 공판, 개점행사,
그랜드세일 등. **PPT로 넣으면** 각 행사의 날짜에 맞춰 **해당 주차 칸에 자동 배치**됩니다.
(PDF로 넣으면 월간 공통 혜택만 채워지고, 날짜 행사는 검토용 파일에 후보로만 정리됩니다.)

### 실행 시 선택 / 표기 규칙
- **실행하면 신한Plus 발급/정기 혜택을 포함할지 물어봅니다.** (Enter=포함, n=제외)
  자동 실행용으로 명령행 옵션도 지원: `--no-발급`, `--no-정기` (또는 `--no-issue`, `--no-regular`).
- PPT의 **`N개점`** 표기는 엑셀에 **`수/분/평/원`** 으로 바꿔 적습니다. (`분` 등 단일점포는 그대로)
- 가전·가구는 **`기본 9%`(가구 `기본 12%`)** 와 **신한P·네이버페이 등록 시 요율**을 함께 표기합니다.

> **왜 PPT가 더 정확한가?** PDF는 글자를 화면 위치 순서로 추출해 이미지에 겹친
> 행사 글자가 뒤섞일 수 있지만, PPT는 글상자마다 텍스트가 온전히 남아 있어
> 날짜별로 정확히 읽어낼 수 있습니다.

## 폴더 구성

```
.
├─ 프로그램 실행.bat        # ⭐ 창(GUI) 실행 (윈도우 더블클릭)
├─ 사은혜택_프로그램.py     # 창(GUI) 본체 (tkinter + 드래그앤드롭)
├─ update_calendar.py     # 핵심 처리 로직 (추출/배치/엑셀 쓰기)
├─ 최초설치.bat            # 최초 1회 라이브러리 설치 (윈도우)
├─ 실행하기.bat            # (대안) 창 없이 자동 처리
├─ requirements.txt       # 필요한 파이썬 라이브러리 목록
├─ 사전고지_양식.xlsx      # 엑셀 양식 (노란색 칸 포함)
├─ 사용설명서.md           # 초보자용 상세 설명서
├─ README.md              # 이 파일
└─ 예제/                   # 연습용 예제 PPT/PDF
```

## 개발자용 참고

- 언어/라이브러리: Python 3, `python-pptx`(PPT 읽기), `pdfplumber`(PDF 읽기), `openpyxl`(엑셀 편집)
- 명령줄 실행:
  ```bash
  pip install -r requirements.txt
  python update_calendar.py [양식.xlsx] [이번달.pptx 또는 .pdf]
  ```
  인자를 생략하면 폴더에서 엑셀 양식과 가장 최근 입력 파일을 자동으로 찾습니다(PPT 우선).
- 설정값(시트 이름, 노란색 칸 위치, 기간 칸 위치)은 `update_calendar.py` 상단 `[설정]` 영역에 모여 있습니다.
- 핵심 함수:
  - `PPT_월간혜택()` / `PPT_날짜행사()` : PPT 글상자에서 월간/날짜 행사 추출
  - `주차범위_읽기()` / `주차찾기()` : 엑셀 기간 칸으로 주차 경계를 잡고 날짜로 주차 배치
  - `PDF_월간혜택()` : PDF 대비책(월간 공통 혜택만)
  - 양식(카드사/금액/혜택률/날짜)이 바뀌면 해당 함수의 정규식만 조정하면 됩니다.
